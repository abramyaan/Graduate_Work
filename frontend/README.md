# Frontend — ПИС «Интеллектуальная оценка резюме на соответствие вакансии»

React-приложение для работы с системой оценки резюме.

## Стек технологий

- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик и dev-сервер
- **React Router** — маршрутизация
- **Axios** — HTTP клиент
- **Tailwind CSS** — стилизация
- **Recharts** — графики и визуализация

## Структура проекта

```
frontend/src/

│   ├── Login.tsx         # Страница входа
│   ├── Dashboard.tsx     # Дашборд с вакансиями
│   ├── Results.tsx       # Таблица результатов по вакансии

```

## Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Убедитесь, что `VITE_API_BASE_URL` указывает на backend:

```
VITE_API_BASE_URL=http://localhost:8000/api
```

### 3. Запуск dev-сервера

```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173

### 4. Сборка для production

```bash
npm run build
```

Результат сборки находится в папке `dist/`.

### 5. Предпросмотр production сборки

```bash
npm run preview
```

## Функционал

### Страница входа (Login)
- Форма авторизации (логин/пароль)
- Сохранение JWT токена в localStorage
- Редирект на дашборд после успешного входа

### Дашборд (Dashboard)
- Список активных вакансий
- Кнопка запуска оценки для каждой вакансии
- Переход к результатам оценки

### Страница результатов (Results)
- Таблица кандидатов по выбранной вакансии
- Цветовая индикация:
  - 🟢 Зелёный: >= 75% — «Пригласить немедленно»
  - 🟡 Жёлтый: 50-74% — «Отложить»
  - 🔴 Красный: < 50% — «Отклонить»
- Отображение баллов по категориям:
  - Навыки (40%)
  - Опыт (30%)
  - Структура (20%)
  - ATS (10%)
- Экспорт результатов в PDF/Excel
- Переход к детальной карточке кандидата

### Карточка кандидата (CandidateDetail)
- Личная информация: ФИО, email, телефон
- Общий балл и рекомендация
- Детализация по категориям с progress bar
- Визуализация:
  - Столбчатая диаграмма (баллы по категориям)
  - Радарная диаграмма (профиль кандидата)
- Ссылка на скачивание резюме

## Роли пользователей

Система поддерживает 3 роли:
- **Admin** — полный доступ
- **Recruiter** — только просмотр результатов и отчётов
- **Operator** — загрузка данных, запуск оценки, просмотр результатов

## API эндпоинты

Приложение взаимодействует со следующими эндпоинтами backend:

- `POST /api/auth/login` — авторизация
- `GET /api/auth/me` — текущий пользователь
- `GET /api/vacancies` — список вакансий
- `GET /api/vacancies/{id}` — детали вакансии
- `GET /api/evaluations/vacancy/{vacancyId}` — результаты по вакансии
- `GET /api/evaluations/{id}` — детали оценки кандидата
- `POST /api/evaluations/run/{vacancyId}` — запуск оценки
- `GET /api/evaluations/export/{vacancyId}?format=pdf|excel` — экспорт


### Типизация

Все компоненты строго типизированы с использованием TypeScript.
Типы API находятся в `src/types/index.ts`.

## Примечания

- Все тексты интерфейса на русском языке
- Используется строгий режим TypeScript
- JWT токен автоматически добавляется к запросам через interceptor
- При 401 ошибке происходит автоматический logout и редирект на /login
- Для графиков используется библиотека Recharts
