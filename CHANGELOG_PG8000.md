## Действия пользователя

### ⚠️ ОБЯЗАТЕЛЬНО

1. **Обновите .env файл:**
   ```env
   DATABASE_URL=postgresql+pg8000://user:pass@localhost:5432/resume_db
   ```

2. **Переустановите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Проверьте подключение:**
   ```bash
   python -m backend.scripts.check_db
   ```

## Преимущества pg8000

✅ **Чистый Python** — не требует компиляции  
✅ **Проще установка** — нет зависимостей от C-библиотек  
✅ **Кроссплатформенность** — работает везде где есть Python  
✅ **Совместимость** — полная поддержка SQLAlchemy 2.0  
✅ **Меньше размер** — ~100 KB vs ~1-2 MB

## Обратная совместимость

Изменения **обратно несовместимы** — требуется обновление .env.

При откате на psycopg2:
1. Вернуть старый драйвер в requirements.txt
2. Убрать `+pg8000` из DATABASE_URL
3. Переустановить зависимости

## Известные ограничения

Нет. pg8000 полностью совместим с функционалом проекта.
