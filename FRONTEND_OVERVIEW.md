# Обзор фронтенд-приложения

## 📦 Что создано

React-приложение для системы оценки резюме с полным функционалом:

- ✅ **4 основные страницы** (Login, Dashboard, Results, CandidateDetail)
- ✅ **API интеграция** с JWT авторизацией
- ✅ **TypeScript** строгая типизация
- ✅ **Tailwind CSS** современный дизайн
- ✅ **Recharts** визуализация данных
- ✅ **React Router** маршрутизация
- ✅ **Компонентная архитектура**

## 🚀 Быстрый старт

```bash
cd frontend

# 1. Установка
npm install

# 2. Настройка
cp .env.example .env
# Отредактировать VITE_API_BASE_URL в .env

# 3. Запуск
npm run dev
# Откроется http://localhost:5173

# 4. Сборка
npm run build
```

## 📡 API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | `/api/auth/login` | Авторизация |
| GET | `/api/auth/me` | Текущий пользователь |
| GET | `/api/vacancies` | Список вакансий |
| GET | `/api/vacancies/{id}` | Детали вакансии |
| GET | `/api/evaluations/vacancy/{id}` | Результаты по вакансии |
| GET | `/api/evaluations/{id}` | Детали оценки |
| POST | `/api/evaluations/run/{id}` | Запуск оценки |
| GET | `/api/evaluations/export/{id}?format=pdf\|excel` | Экспорт |

## 🏗️ Архитектурные решения

```
      ├─ Component 1
      ├─ Component 2
      └─ Component 3
```

### API слой
```
Page → API client → Axios interceptors → Backend
                    ↓ (401)
                  Logout → /login
```

### Типизация
```
Backend Schema → TypeScript interfaces → Components
```
